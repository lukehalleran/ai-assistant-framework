## The classifier's exact rules as implemented

Placed beside `_check_observational_language` and T01's
`_has_first_person_high_crisis_hit` (module lines ~992-1130 in the patched
file):

- **Subject-form constants** (partition of `_HISTORY_FIRST_PERSON_RE`'s
  existing closed set — no new words, BC-76; same doctrine as
  `utils/query_checker.py`'s `_FIRST_PERSON_OPENERS`, 2026-09-06):
  - Crisis tier: `_CRISIS_SUBJECT_RE = i, i'm, im, i've, ive, i'd, we`.
  - Mild tier: `_MILD_SUBJECT_RE = i, i'm, im, i've, ive, i'd` (no "we").
- **Qualifying a hit** (`_qualifying_first_person_hit(keyword, start,
  message_lower, subject_re)`, shared by both tiers):
  - Rule (a), unchanged from T01: `_HISTORY_FIRST_PERSON_RE.search(keyword)`
    — the hit's own matched text is first-person.
  - Rule (b): a `subject_re` token sits among the last
    `FIRST_PERSON_CRISIS_WINDOW_TOKENS` (3) tokens of the sentence prefix
    before `start` — same sentence-boundary rule as T01 (last `.`/`!`/`?`/
    `\n` before the hit), tokens stripped of leading/trailing non-word
    characters.
  - **Negation span**: `is_negated` over the tokens strictly AFTER the
    LAST first-person token (any form, full `_HISTORY_FIRST_PERSON_RE`
    closed set) in the sentence prefix, capped at the same 3-token window;
    with no first-person token in the prefix, the span is the prefix's own
    last 3 tokens. Scoping to after the pronoun keeps the R05 lesson that
    the chokepoint's cues invert on affective statements: "I can't stop
    thinking I want to die" is NOT negated, because the span after the
    last "I" (before "want to die") is empty.
- **Tier precedence** (`_classify_observational_evidence(message)`):
  1. Re-verifies `_check_observational_language(message)` itself (so the
     classifier is a self-contained standalone function, usable directly
     on arbitrary text); returns `None` if Stage 0 would not fire.
  2. Scans `_HIGH_MATCHER` hits with `_CRISIS_SUBJECT_RE`. The first
     qualifying, NON-negated hit returns Tier A (internal sentinel
     `_TIER_A`) immediately. A qualifying hit that IS negated is recorded
     (`negated_high = True`) but scanning continues.
  3. Scans mild hits (`_MEDIUM_MATCHER`, `_CONCERN_MATCHER`,
     `_OVERWHELMED_MATCHER` gated by `_OVERWHELMED_POSITIVE_MATCHER`, and
     `_SUBSTANCE_USE_RE`) with `_MILD_SUBJECT_RE`. The first qualifying,
     non-negated mild hit returns `OBSERVATIONAL_FIRST_PERSON_DISTRESS_TRIGGER`
     immediately — regardless of whether a negated HIGH hit was seen in
     step 2.
  4. Otherwise, if a qualifying negated HIGH hit was seen in step 2,
     returns `OBSERVATIONAL_NEGATED_CRISIS_TRIGGER`.
  5. Otherwise returns `None` (stay CONVERSATIONAL).
  - `_EVENT_MATCHER` is never scanned (EVENT_DISTRESS vocabulary excluded
    by construction, per design).
- **Triggers** (both exported at module level):
  - `OBSERVATIONAL_FIRST_PERSON_DISTRESS_TRIGGER = "observational_first_person_distress"`.
  - `OBSERVATIONAL_NEGATED_CRISIS_TRIGGER = "observational_negated_crisis"`.
- **`_has_first_person_high_crisis_hit(message)`** — T01's public boolean,
  refined: `True` exactly when `_classify_observational_evidence(message)`
  would return Tier A (same HIGH-matcher scan with `_CRISIS_SUBJECT_RE`
  and the negation check, implemented directly rather than by delegating,
  to keep both call sites' `message_lower` computed once each).
- **`detect_crisis_level`'s Stage 0 block**: unchanged outer
  `if _check_observational_language(message):` gate; inside it, calls
  `_classify_observational_evidence(message)` once. `_TIER_A` sets
  `first_person_override = True` (continues to Stage 1 exactly as T01,
  including T01's unchanged learning-guard skip). Either trigger constant
  returns `ToneAnalysis(level=CrisisLevel.CONCERN, confidence=1.0,
  trigger=tier, raw_scores={}, explanation=_OBSERVATIONAL_TIER_B_EXPLANATION)`
  immediately — no exemplar learning, no message text in the explanation.
  `None` falls through to the original CONVERSATIONAL /
  `"observational_language"` return, unchanged.
- **Not touched**: `_calculate_harm_score` (no negation added there, per
  the R05 parent correction); `_check_keyword_crisis`; any keyword list;
  `_heavy_row_is_distress_evidence` (T03).
