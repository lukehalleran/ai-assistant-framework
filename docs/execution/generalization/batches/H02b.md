## Owner visibility

- **Arbiter-floor decision**: per contract item 5, a deterministic
  `domain_strain` hit outranks an arbiter's CONVERSATIONAL verdict —
  consistent with the existing `borderline_backstop` precedent (a
  deterministic distress signal already outranks a CONVERSATIONAL arbiter
  verdict there). Verified by `test_floor_path_arbiter_llm_fallback`: a
  stubbed arbiter returning CONVERSATIONAL still gets floored to CONCERN.
- **Newline-boundary limitation** (contract item 4): the rule reuses
  `_qualifying_first_person_hit`'s sentence boundary (`.!?\n`), so a line
  wrap that lands BETWEEN the domain anchor and the strain evidence hides
  the pair — this is an accepted, inherited limitation of reusing that
  boundary (changing it would diverge from T01/T02's own newline handling).
  All 24 STRESS rows' wrap points were chosen to keep the anchor+strain
  window on one side of the wrap (`lead_words=1` default, `0` for the two
  short rows where the qualifying subject is itself the first word —
  `we_might_lose_apartment`, `cant_keep_up_classes`); no row in this
  batch's fixture set needed to be skipped for lacking a safe wrap
  placement, but the limitation itself is real and would surface on a
  message where the wrap point is outside the author's control (e.g. a
  narrow mobile client wrapping mid-clause).
