### Parent fix D5: thread-break markers ignore negation

**Finding.** The shared negation cues (`never`, `stop`, `skip`, `avoid`, `rather than`, `instead of`, checked over 5 tokens across punctuation) routinely come just before a real topic change: "never mind, moving on…", "ok stop, different topic…", "skip that. new question…".

- **Before R06:** these were breaks.
- **After R06's negation-aware version:** they were not.
- **Consequence:** `calculate_thread_continuity_score` stopped forcing 0.0, so `memory/thread_manager.py` continued the old thread and kept its context.
- **Negation bought little:** bare "not" is not a cue, so it protected only rare forms.

This is the same lesson as R05's "overwhelmed": a marker that states the act itself should ignore negation.
