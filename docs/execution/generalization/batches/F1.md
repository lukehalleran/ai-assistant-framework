## 7. Contract as implemented

`utils/retrieval_outcome.py` (87 lines):
- Imports: `from __future__ import annotations` only — no project imports,
  no `logging`, no side effects on import.
- `RETRIEVAL_STATES = frozenset({"succeeded", "no_results", "unavailable", "failed"})`.
- `class RetrievalError(RuntimeError)`: keyword-only `source: str`,
  `reason: str`; `__init__` calls `super().__init__(f"{source}: {reason}")`
  so `str()` includes both (inherited `Exception.__str__` reads `args[0]`).
  Docstring documents `reason` as a short constant-style label/exception
  class name, never user text.
- `class OutcomeList(list)`: `__init__(self, items=(), *, status=None,
  reason="")`. `status=None` derives `succeeded`/`no_results` from
  contents; an explicit status not in `RETRIEVAL_STATES` raises
  `ValueError`; non-empty items with `status="no_results"` raises
  `ValueError`; `failed`/`unavailable` with items is allowed (partial read).
  Classmethods `OutcomeList.failed(reason, items=())` and
  `OutcomeList.unavailable(reason, items=())`. No `__eq__`/`__bool__`
  override, so equality/truthiness stay plain-list by inheritance.
  Docstring documents that slicing, `list(x)`, `+` and `.copy()` return a
  plain `list` and drop `status`/`reason` (standard `list`-subclass
  behavior, not added logic) — proven by tests, not asserted only in prose.
- `def outcome_status(value) -> tuple[str, str]`: `isinstance(value,
  OutcomeList)` → `(value.status, value.reason)`; else `("succeeded", "")`
  if `value` is truthy, else `("no_results", "")` — covers a plain
  non-empty/empty list, `None`, and `""` in one branch, matching the
  contract's four listed cases exactly (nothing else handled).

### Tests (`tests/unit/test_retrieval_outcome.py`, 291 lines, 39 tests)

- States: `test_states_are_the_four_reused_names` (exact frozenset);
  `test_parity_with_insight_channel_states` — **the CHANNEL_STATES parity
  test**: `RETRIEVAL_STATES <= CHANNEL_STATES`, importing
  `core.insight.coordinator.CHANNEL_STATES` live (not touched, only read).
- `OutcomeList`: derived status (empty/non-empty), explicit
  failed/unavailable with and without items, explicit `succeeded` with
  items, unknown-status `ValueError`, non-empty+`no_results` `ValueError`,
  both classmethods (with and without items), empty-failed `== []` and
  falsy, non-empty truthy, `isinstance(..., list)`, and four drop-on-transform
  tests (`[1:]` slice, `list(x)`, `x + [..]`, `x.copy()` — each asserts
  `type(...) is list` and `not hasattr(..., "status")`).
- `RetrievalError`: fields, `str()` contains both `source` and `reason`,
  `isinstance(..., RuntimeError)`, raise/catch as bare `Exception`, and
  keyword-only enforcement (`TypeError` on positional args).
- `outcome_status`: all four `OutcomeList` states, plain empty list, plain
  non-empty list, `None`, `""`.
- **Leaf-import guard and its negative control**: `_top_level_import_names`
