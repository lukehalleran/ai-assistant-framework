Callers (including the CGR-20260913-007 gatherers) cannot surface the failure.

This is a bounded structural review, not a reproduced runtime failure. If
the source owner shows a site is not an instance of the class, the response
should say so with deployed-function evidence. The class-guard owner then
decides between a detector change and continued accepted debt.
