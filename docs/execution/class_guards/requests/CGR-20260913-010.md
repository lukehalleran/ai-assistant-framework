## Observed shape and semantic risk

`store_interaction`, `store_skill` (two handlers), `store_proposal`, `store_thread` and `add_conversation_memory` return None on any exception — the same value as a deliberate skip (and `add_conversation_memory` is annotated to return str). A turn or artifact can silently not persist while callers proceed as if it did.

This is a bounded structural review, not a reproduced runtime failure. If
the source owner shows a site is not an instance of the class, the response
should say so with deployed-function evidence. The class-guard owner then
decides between a detector change and continued accepted debt.

## Requested remedy (the source owner owns the design)

Separate deliberate skips from failures (typed outcome, or raise for failures) and make callers record or surface a failed write.

## Expected deployed-function regression tests

Deployed write calls with an injected raising collection assert a failure outcome distinct from each deliberate-skip path (empty response, error sentinel, dedup) and no success-shaped receipt; paired success controls.
